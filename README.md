# AegisPOS releases

Installers for AegisPOS, the point of sale for retail shops. **No source code is kept here.**

- **Install:** download `AegisPOS_<version>_x64-setup.exe` from the latest release and run it.
- **Update:** AegisPOS checks this page itself and offers new versions in *Settings > Updates*.
  Every installer is signed; the app refuses one that isn't, wherever it came from.
- **License:** a new shop runs fully for 30 days. After that, new sales need a license file
  from your AegisPOS seller. Your records, reports and backups always stay available.
